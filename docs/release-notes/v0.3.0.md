**Scarlet Meter 0.3.0**, a DPS meter for AION 2 with its own overlay on top of
[RATmeter](https://github.com/Kuroukihime/AIon2-Dps-Meter)'s packet decoding (RATmeter v1.11.5.341, as in 0.2.0).

> **Early release.** Its in-game checks are not finished, so numbers may be off. Reports are welcome in
> [Issues](https://github.com/harrynguon/Scarlet-Meter/issues).

## Download and run

1. Install [Npcap](https://npcap.com) with **"Install Npcap in WinPcap API-compatible Mode"** ticked (and
   "Restrict Npcap driver's access to Administrators only" unticked, so the meter needs no administrator rights).
2. Download `ScarletMeter-0.3.0-win-x64.zip` below and unzip it anywhere you can write to (Documents, Desktop; not
   Program Files). Updating from 0.2.0: unzip it over a copy elsewhere, then move your old `data` folder (settings,
   history, logs) into the new `ScarletMeter` folder.
3. Start the game, then run `ScarletMeter\ScarletMeter.exe`. Nothing else to install: .NET is built in.

Settings, history and logs stay in a `data` folder beside the exe. To see the meter with made-up fights, open a
terminal in the `ScarletMeter` folder and run `.\ScarletMeter.exe --demo`. Windows may warn that the file is from an
unknown publisher (it is not code-signed): choose "More info", then "Run anyway". The `.sha256` files have each
zip's checksum (`Get-FileHash` in PowerShell).

## Highlights

- **World events as a row of icons.** One icon per event, lit with the minutes and seconds to go; hover for what it
  is, click for its countdown.
- **A bar area that sizes itself.** A bar per player up to five, the rest scroll with your own bar pinned in view;
  nothing to resize by hand.
- **A pause in the Abyss**, whose crowds slow any meter down; Settings, About shows the map you are on.
- **Other players' training-dummy fights ignored**, and **Odyle energy** beside the ping.
- **Boss encounters only** is on for a new install. If you already use the meter, your setting is kept as it was.
