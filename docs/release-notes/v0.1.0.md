The first public build of **Scarlet Meter**, a DPS meter for AION 2 with its own overlay on top of
[RATmeter](https://github.com/Kuroukihime/AIon2-Dps-Meter)'s packet decoding (RATmeter v1.11.5.341).

> **Early release.** Its in-game checks are not finished, so numbers may be off. Reports are welcome in
> [Issues](https://github.com/harrynguon/Scarlet-Meter/issues).

## Download and run

1. Install [Npcap](https://npcap.com) with **"Install Npcap in WinPcap API-compatible Mode"** ticked (and
   "Restrict Npcap driver's access to Administrators only" unticked, so the meter needs no administrator rights).
2. Download `ScarletMeter-0.1.0-win-x64.zip` below and unzip it anywhere you can write to (Documents, Desktop; not
   Program Files).
3. Start the game, then run `ScarletMeter\ScarletMeter.exe`. Nothing else to install: .NET is built in.

Settings, history and logs stay in a `data` folder beside the exe. To see the meter with made-up fights, open a
terminal in the `ScarletMeter` folder and run `.\ScarletMeter.exe --demo`. Windows may warn that the file is from an
unknown publisher (it is not code-signed): choose "More info", then "Run anyway". The `.sha256` files have each
zip's checksum (`Get-FileHash` in PowerShell).

## What's in it

- An overlay with a boss card (HP, **Kill in** estimate), each player's DPS, damage, share and combat power, and
  class colours.
- Animated bar effects per class (slashes, arrows, fire and ice, poison...), a glide when someone overtakes, and
  switches to tone them down or off.
- Player details (skills, buffs, damage graph, combat log), saved boss fights, a background picture with its own
  opacity, a global hotkey (Ctrl+Shift+D), and world-event notices that step aside during boss fights (Global
  preset times, not yet verified).
